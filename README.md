# 🏦 AYB Yield Farming Protocol

An institutional-grade staking dashboard built on Arbitrum One. This platform allows users to lock their AYB tokens and earn dynamic rewards based on three performance tiers.

## 🌟 Key Features
* Tiered Rewards: Bronze (15%), Silver (35%), and Gold (80%) APY.
* Real-time On-chain Data: Live tracking of TVL, pending rewards, and personal stake.
* Referral System: Built-in network growth incentives (5% reward share).
* Emergency Exit: Instant capital and reward withdrawal functionality.

## 🛠 Tech Stack
* Contracts: Solidity (verified on Arbiscan).
* Frontend: Tailwind CSS & Ethers.js.
* Network: Arbitrum Layer 2.
